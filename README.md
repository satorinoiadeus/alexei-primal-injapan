# Alexei: Primal in Japan

Original Ren'Py romantic comedy about Alexei, a tall carnivore-diet enthusiast dating in Tokyo. All romantic characters are adults.

## Play
Install the [Ren'Py SDK](https://www.renpy.org/latest.html), place this repository in your Ren'Py projects directory, and select Launch Project.

## Build Windows
In Ren'Py Launcher, choose Build Distributions and select Windows/PC. The SDK creates a distribution with a Windows executable.

## Build Android
Install the Ren'Py Android tooling (RAPT) through the launcher, configure Android, then choose Build Package. SDK, signing and Android dependencies are required.

## Content
Three romance routes, choices, four endings, comedy, kisses, and fade-to-black intimacy. No explicit sexual content. Text-only prototype; no artwork or music included.
